  
**201. UIMP - DESCRIPCIÓN DEL ENTORNO**

**1. Introducción**

Este documento detalla la infraestructura técnica, niveles de aplicación y capas de responsabilidad del sistema CONTAPRE, proporcionando una visión integral del entorno en el que opera la aplicación.

**2. Base Tecnológica**

- **Lenguaje de programación:** C#

- **Framework:** .NET Framework 4.8

- **Arquitectura Web:** WebForms

- **Componentes de terceros:** Telerik

- **Biblioteca de JavaScript:** jQuery 3.4.1

- **Navegador recomendado:** Google Chrome (optimizado para este navegador).

**3. Niveles de Aplicación (Lógica Física)**

El sistema CONTAPRE está organizado en los siguientes niveles de aplicación, cada uno con responsabilidades específicas:

1.  **Dimatica.ContaPre.BLL (Business Logic Layer)**  
    Implementa la lógica de negocio de la aplicación, asegurando que los procesos cumplan con las reglas establecidas.

2.  **Dimatica.ContaPre.DAL (Data Access Layer)**  
    Se encarga de la comunicación directa con las bases de datos, gestionando las operaciones CRUD y la interacción con Oracle y SQL Server.

3.  **Dimatica.ContaPre.OL (Object Layer)**  
    Contiene las definiciones de objetos y estructuras de datos utilizados en la lógica de negocio y las capas de presentación.

4.  **Dimatica.ContaPre.Presentation**  
    Representa la capa de presentación, desarrollada en WebForms, donde los usuarios interactúan con el sistema. Incluye componentes de Telerik para la interfaz de usuario.

5.  **Dimatica.ContaPre.PresentationUnitTest**  
    Contiene pruebas unitarias para validar el correcto funcionamiento de la capa de presentación.

**4. Capas de Aplicación (Separación de Responsabilidades)**

El diseño del sistema sigue el principio de separación por capas para garantizar modularidad y facilidad de mantenimiento:

1.  **Capa de Presentación:**  
    Interacción del usuario con la aplicación mediante WebForms y componentes Telerik.

2.  **Capa de Lógica de Negocio:**  
    Gestiona las reglas de negocio y controla el flujo de datos entre la presentación y el acceso a datos.

3.  **Capa de Acceso a Datos:**  
    Se ocupa de las operaciones con las bases de datos subyacentes (SQL Server y Oracle).

4.  **Capa de Datos:**  
    Define los objetos y entidades que representan los datos almacenados en las bases de datos.

**5. Niveles de Infraestructura**

El sistema se distribuye entre las siguientes capas de infraestructura:

1.  **Base de Datos - SQL Server 12:**  
    Hospedada en la misma máquina que la aplicación. Gestiona la mayor parte de los datos transaccionales del sistema.

2.  **Base de Datos - Oracle 19c:**  
    Ubicada en un servidor independiente. Gestiona datos específicos que requieren interoperabilidad con otros sistemas.

3.  **Servidor de Aplicaciones:**

    - Sistema Operativo: **Windows Server 2012**.

    - Funciona como servidor web y de lógica de negocio.

    - Configuración optimizada para ejecutar aplicaciones .NET Framework 4.8.

    - Navegador recomendado para usuarios: **Google Chrome**.

**6. Entornos**

El sistema CONTAPRE cuenta con tres entornos para el desarrollo, prueba y despliegue de la aplicación:

1.  **LOCALHOST:**  
    Entorno de desarrollo individual, configurado en los equipos de los desarrolladores.

2.  **DESARROLLO:**  
    Utilizado para pruebas de integración y validación de cambios antes de su despliegue en producción.

3.  **PRODUCCIÓN:**  
    Entorno final utilizado por los usuarios finales. Configurado en un servidor dedicado con acceso controlado.

**7. Resumen y Dependencias**

- **Infraestructura tecnológica:**

  - Lenguaje: C#, .NET Framework 4.8

  - Bases de datos: SQL Server 12 y Oracle 19c

  - Interfaz de usuario: Telerik y jQuery 3.4.1

  - Servidor: Windows Server 2012

- **Dependencias principales:**

  - Conectores para SQL Server y Oracle.

  - Componentes Telerik para la interfaz de usuario.

- **Interacción entre entornos:**

  - Flujo de datos sincronizado entre SQL Server y Oracle.

  - Configuración específica en cada entorno para replicar la arquitectura de producción.

**8. Configuraciones de Optimización**

- **Rendimiento del servidor:**

  - Configuración de IIS para ejecutar aplicaciones .NET de alto rendimiento.

  - Monitorización de recursos del servidor (CPU, RAM, almacenamiento) para evitar cuellos de botella.

- **Compatibilidad del navegador:**

  - La aplicación está optimizada para funcionar en Google Chrome.

  - Otras configuraciones de compatibilidad pueden ser consideradas para navegadores alternativos si es necesario.
