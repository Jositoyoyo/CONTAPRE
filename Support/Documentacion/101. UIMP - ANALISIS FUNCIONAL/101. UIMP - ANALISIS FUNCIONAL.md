### **101. UIMP - ANÁLISIS FUNCIONAL** 

#### **1. Introducción**

CONTAPRE es una aplicación de contabilidad presupuestaria desarrollada desde cero por Dimática, diseñada para gestionar de forma integral los presupuestos, ingresos, gastos, listados y registros asociados a la tesorería. Este documento describe las funcionalidades principales del sistema, los flujos de trabajo, y los módulos en los que se estructura la aplicación.

#### **2. Propósito del Sistema**

CONTAPRE tiene como objetivo principal facilitar la contabilidad presupuestaria en la organización, permitiendo la gestión eficiente de ingresos, gastos y operaciones extrapresupuestarias. Además, proporciona herramientas para la consulta, generación de listados y manejo de datos relacionados con la tesorería.

#### **3. Alcance**

El análisis funcional se centra en los siguientes módulos y funcionalidades:

- **Presupuestos:** Gestión de ingresos, gastos y modificaciones de crédito.

- **Ingresos:** Gestión de expedientes, agrupación de datos y consulta del estado de cuentas restringidas.

- **Gastos:** Administración de expedientes, consultas y comprobaciones.

- **Listados:** Generación de informes para diferentes tipos de operaciones.

- **Tesorería:** Gestión de hojas de arqueo, apuntes y registro de pagos.

- **Operaciones extrapresupuestarias:** Registro y consulta de operaciones fuera del presupuesto.

- **Tablas y configuración del sistema.**

#### **4. Descripción General del Sistema**

- **Usuarios involucrados:**

  - **Administradores:** Configuran el sistema, gestionan usuarios y supervisan la integridad de los datos.

  - **Operadores contables:** Introducen y consultan datos relacionados con presupuestos, ingresos, gastos y tesorería.

  - **Auditores:** Consultan los registros y listados para realizar verificaciones, pero no pueden modificar los datos.

- **Interfaces principales:**

  - **Menús interactivos:** Organizados por módulos temáticos para facilitar el acceso a las funcionalidades principales.

  - **Tablas dinámicas:** Componentes que permiten la visualización y edición de datos.

  - **Listados y reportes:** Herramientas para la generación y exportación de informes en formatos como Excel y PDF.

#### **5. Módulos Funcionales**

1.  **Presupuestos**

    - **Ingresos:** Registro y consulta de ingresos presupuestarios.

    - **Gastos:** Registro de gastos asociados a presupuestos.

    - **Modificaciones de Crédito:** Gestión de ajustes presupuestarios, incluyendo aumentos o reducciones de crédito.

2.  **Ingresos**

    - **Expedientes:** Gestión de expedientes relacionados con ingresos.

    - **Agrupar DR:** Herramienta para consolidar datos de ingresos.

    - **Estado Cuentas Restringidas:** Consulta del estado financiero de cuentas específicas.

3.  **Gastos**

    - **Expedientes Administrativos:** Gestión de expedientes asociados a gastos administrativos.

    - **Consulta Aplic/Importe:** Herramienta para verificar la aplicación y montos de los gastos.

    - **Comprobación de Expedientes:** Validación de datos ingresados en expedientes.

    - **Consulta de Facturas de Compra:** Permite visualizar facturas registradas.

4.  **Listados**

    - **Listados de Gastos, Ingresos y Extrapresupuestarios:** Generación de informes detallados de las operaciones realizadas en cada área.

    - **Listados de Tesorería:** Informes financieros específicos de la tesorería.

5.  **Tesorería**

    - **Asignar Hoja de Arqueo:** Permite asignar hojas de arqueo para registrar operaciones.

    - **Ver Hoja de Arqueo:** Consulta y validación de las hojas asignadas.

    - **Apuntes de Tesorería:** Registro de transacciones financieras en tesorería.

    - **Alta de Registro de Pagos:** Herramienta para registrar pagos realizados.

6.  **Extrapresupuestarias**

    - Registro y gestión de operaciones que no forman parte del presupuesto principal.

7.  **Tablas y Sistema**

    - Configuración de tablas base, como aplicaciones y cuentas restringidas, que son esenciales para el funcionamiento del sistema.

#### **6. Flujos de Trabajo Principales**

1.  **Registro de Ingresos Presupuestarios**

    - El usuario accede al módulo de **Presupuestos \> Ingresos**.

    - Introduce los datos requeridos en el formulario.

    - El sistema valida los datos y los almacena en la base de datos SQL Server.

2.  **Consulta de Gastos**

    - El usuario selecciona **Gastos \> Consulta Aplic/Importe**.

    - Define los filtros de búsqueda y ejecuta la consulta.

    - El sistema muestra los resultados en una tabla interactiva y permite exportarlos.

3.  **Generación de Listados de Tesorería**

    - Acceso a **Listados \> Listados Tesorería**.

    - Selección de criterios específicos (fecha, tipo de operación).

    - Generación y descarga del listado en formato Excel o PDF.

4.  **Gestión de Hojas de Arqueo**

    - El usuario accede a **Tesorería \> Asignar Hoja de Arqueo**.

    - Registra la hoja y asocia transacciones.

    - Los datos se sincronizan automáticamente con la base de datos SQL Server.

#### **7. Requisitos Funcionales**

1.  **Gestión de Presupuestos:**

    - Validación de datos al registrar ingresos y gastos.

    - Gestión de modificaciones presupuestarias.

2.  **Consultas:**

    - Búsquedas rápidas mediante filtros.

    - Exportación de resultados a formatos Excel y PDF.

3.  **Tesorería:**

    - Registro y validación de hojas de arqueo.

    - Alta y modificación de pagos.

4.  **Listados:**

    - Generación de reportes en tiempo real.

    - Visualización amigable para el usuario.

#### **8. Requisitos No Funcionales**

1.  **Rendimiento:**

    - Respuesta en tiempo real para consultas y generación de listados.

2.  **Seguridad:**

    - Control de acceso mediante roles.

    - Cifrado de datos sensibles en tránsito (HTTPS).

3.  **Compatibilidad:**

    - Optimizado para Google Chrome.
