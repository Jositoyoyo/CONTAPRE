### **301. UIMP - MANUAL DE ADMINISTRACIÓN Y DE OPERACIONES**

#### **1. Introducción**

Este manual proporciona las instrucciones necesarias para la administración y operación del sistema CONTAPRE. Está dirigido a administradores y operadores responsables de gestionar el sistema, supervisar su correcto funcionamiento, y realizar tareas de mantenimiento operativo.

#### **2. Propósito del Manual**

El objetivo de este manual es:

- Facilitar la administración de usuarios y roles en el sistema.

- Proporcionar lineamientos para realizar tareas operativas clave, como la consulta y registro de datos presupuestarios.

- Establecer procedimientos para solucionar problemas comunes.

#### **3. Estructura del Sistema**

CONTAPRE está estructurado en varios módulos funcionales:

- **Presupuestos:** Gestión de ingresos, gastos y modificaciones de crédito.

- **Ingresos y Gastos:** Operaciones específicas para cada tipo.

- **Listados:** Generación de informes.

- **Tesorería:** Gestión de apuntes y registro de pagos.

- **Configuración del sistema:** Administración de tablas y datos base.

#### **4. Administración del Sistema**

##### 4.1 Gestión de Usuarios

Los usuarios de CONTAPRE se agrupan en roles con permisos específicos. Solo los administradores pueden gestionar usuarios.

1.  **Crear un Usuario Nuevo:**

    - Accede a la opción de **Sistema \> Usuarios.**

    - Completa los datos requeridos, como nombre, usuario, contraseña y rol asignado.

    - Guarda los cambios.

2.  **Modificar Permisos:**

    - Selecciona un usuario existente en la lista.

    - Edita los roles asignados según sus responsabilidades.

    - Confirma los cambios.

3.  **Eliminar o Desactivar Usuarios:**

    - Selecciona al usuario en la lista.

    - Elige la opción de **Desactivar** para mantener su historial o **Eliminar** si ya no es necesario.

#### **5. Operaciones Principales**

##### 5.1 Gestión de Presupuestos

1.  **Registrar un Ingreso Presupuestario:**

    - Navega a **Presupuestos \> Ingresos.**

    - Completa el formulario con los datos del ingreso (código, descripción, monto, etc.).

    - Valida los datos y confirma el registro.

2.  **Registrar un Gasto Presupuestario:**

    - Accede a **Presupuestos \> Gastos.**

    - Rellena los campos necesarios, como importe, partida presupuestaria, y descripción.

    - Guarda los cambios.

3.  **Modificar Créditos Presupuestarios:**

    - Selecciona **Presupuestos \> Modificaciones de Crédito.**

    - Introduce el tipo de modificación (aumento/reducción) y los montos.

    - Confirma los ajustes.

##### 5.2 Consultas y Listados

1.  **Consultar Ingresos/Gastos:**

    - Accede a **Ingresos \> Expedientes** o **Gastos \> Consulta Aplic/Importe.**

    - Aplica los filtros deseados (por ejemplo, fechas, códigos).

    - Visualiza los resultados en la tabla.

2.  **Generar Listados:**

    - Dirígete a **Listados \> Listados Gastos/Ingresos.**

    - Selecciona los criterios (rango de fechas, tipo de transacción, etc.).

    - Descarga el listado en formato Excel o PDF.

##### 5.3 Gestión de Tesorería

1.  **Asignar Hoja de Arqueo:**

    - Entra a **Tesorería \> Asignar Hoja de Arqueo.**

    - Selecciona la hoja correspondiente y completa la información necesaria.

    - Guarda los cambios.

2.  **Registrar Pagos:**

    - Navega a **Tesorería \> Alta Registro Pagos.**

    - Introduce los detalles del pago, como beneficiario, monto, y fecha.

    - Confirma el registro.

##### 5.4 Operaciones Extrapresupuestarias

1.  **Registrar Operaciones Extrapresupuestarias:**

    - Accede al módulo **Extrapresupuestarias.**

    - Completa los datos del registro (tipo, monto, descripción).

    - Guarda los cambios.

#### **6. Monitorización del Sistema**

##### 6.1 Verificación de Datos

- Consulta los logs del sistema para identificar inconsistencias.

- Valida periódicamente los datos sincronizados entre las bases de datos SQL Server y Oracle.

##### 6.2 Generación de Reportes de Auditoría

- Genera reportes desde **Listados** para verificar transacciones realizadas.

- Comparte los resultados con el equipo de auditoría según sea necesario.

#### **7. Solución de Problemas Comunes**

| **Problema**                             | **Solución**                                                                                   |
|------------------------------------------|------------------------------------------------------------------------------------------------|
| No se puede acceder al sistema           | Verifica la conexión a la red y el estado del servidor (Windows Server 2012).                  |
| Los datos no se actualizan correctamente | Revisa los logs del sistema para identificar posibles errores de sincronización.               |
| Error al generar un listado              | Asegúrate de que los filtros aplicados sean correctos. Verifica el estado de la base de datos. |
| Usuario no puede realizar operaciones    | Revisa los permisos asignados al usuario desde **Sistema \> Usuarios.**                        |

#### **8. Buenas Prácticas de Operación**

- Realiza copias de seguridad de la base de datos regularmente.

- Supervisa los logs de actividad para detectar posibles incidencias.

- Utiliza Google Chrome como navegador principal para asegurar la compatibilidad.

- Informa de errores críticos al equipo de soporte técnico de UIMP.

#### **9. Actualización del Sistema**

1.  **Preparación del Entorno:**

    - Realiza un respaldo completo de las bases de datos (SQL Server y Oracle).

    - Verifica que todos los usuarios hayan cerrado sesión.

2.  **Instalación de Actualizaciones:**

    - Sigue las instrucciones del **Manual de Despliegue** (401. UIMP).

    - Asegúrate de probar las nuevas funcionalidades en el entorno de desarrollo antes de implementarlas en producción.

#### **10. Conclusión**

Este manual proporciona una guía detallada para la administración y operación de CONTAPRE, asegurando que las tareas del día a día se lleven a cabo de manera eficiente y segura. Su correcto uso garantizará la estabilidad y el buen desempeño del sistema.
